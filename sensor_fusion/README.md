# Autonomous Navigation & Sensor Fusion System
**故障検知機能を備えた2D自律航行シミュレーションシステム**

## 🌟 概要
本プロジェクトは、4つのセンサー（車輪速、GPS、加速度、ジャイロ）の情報を統合（フュージョン）し、一部のセンサーが故障しても正確な自己位置を推定し続けるシステムを実装したものです。

## 🛠 特徴
- **マルチセンサー統合**: カルマンフィルタを用いた高度な推論ロジック。
- **フェイルセーフ設計**: 多数決アルゴリズムにより、異常値を出すセンサーを自動的に切り離します。
- **3層アーキテクチャ**: 
  - `main`: 全体の制御
  - `sensor_fusion`: 計算ロジック（ポータブルな設計）
  - `simulator`: 仮想的な走行環境と故障シナリオの生成
- **日本語コメント完備**: 日本語環境での開発・保守を想定した詳細なドキュメンテーション。
